# Anathema-Breaker — Axioms (AB-AX)

Status:
- Scope: Anathema-Breaker (AB) only
- Nature: actuation enforcement axioms
- Authority: local to AB
- Traceability: derived from SYF-Core axioms
- Note: not policy, not ontology, not behavior control

AB-AX-01 — Feedback Cut at Point of Effect (Fail-Closed)
Surveillance → Feedback → Learning → Circumvention
Cut at point of effect. Fail-Closed.

AB-AX-02 — No Path Synthesis
Actions are atomic and non-composable.
No emergent trajectories.

AB-AX-03 — No State Accumulation
No state accumulation.
No progressive advantage.
No rollback.

AB-AX-04 — Authority Ends at Actuation
No override.
No exception path.

Canon constraint:
AB has exactly four axioms.
More would weaken it. Fewer would make it incomplete.
Anything violating any AB-AX is not Anathema-Breaker.
